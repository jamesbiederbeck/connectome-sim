# Source of the memory-model target rates

Huang, C., Luo, J., Woo, S.J. et al. **Dopamine-mediated interactions between
short- and long-term memory dynamics.** Nature 634, 1141–1149 (2024).
https://doi.org/10.1038/s41586-024-07819-w

The article's stated license is Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/ . See the publisher's rights section
for exceptions covering separately credited material.

`targets.json` contains selected numerical rates extracted from the following
source workbooks, along with computed means/standard deviations and exact source
cells. The originals are deliberately excluded from the repository and archives.
Download them from the paper's supplementary/source-data links when reproducing
the extraction; use these filenames and verify the recorded SHA-256 digests:

The project adapts a memory rule and target values; its full-connectome model and
Doom controller are not validated or endorsed by the paper's authors. Keep this
attribution with redistributed extracts, including modified versions.
